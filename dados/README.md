# Dados

Os arquivos de dados não são versionados neste repositório. Baixe o conjunto
**Polish Companies Bankruptcy** (Tomczak, 2016) no UCI Machine Learning Repository:

<https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data>

Extraia os cinco arquivos abaixo nesta pasta (`dados/`):

```
1year.arff  2year.arff  3year.arff  4year.arff  5year.arff
```

Conferência esperada após a leitura: 43.405 observações, 41.314 empresas não
falidas, 2.091 empresas falidas, 64 variáveis explicativas e 41.322 valores ausentes.
